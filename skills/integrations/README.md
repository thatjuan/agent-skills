# Integrations

API, SDK, and tool domain expertise that triggers off your code context — an import, an endpoint, an auth header, or a direct question about the service.

- **[cloudbeds-api](./cloudbeds-api/SKILL.md)** — Cloudbeds hospitality API for property-management, booking, payments, accounting, and channel integrations.
- **[forge-suite](./forge-suite/SKILL.md)**: Operate Salesforge, Warmforge, and Mailforge through their REST APIs. Domains and mailboxes, warmup and placement, email + LinkedIn sequences, replies, and webhooks.
- **[typesafe-ai](./typesafe-ai/SKILL.md)** — Build application logic on TypeSafe AI's Jev decision model: typed Choice, Score, and Noul questions over a state, calibrated answers, control flow in code.
- **[unifi-operator](./unifi-operator/SKILL.md)** — Operate UniFi Network and Protect through their local APIs on a UDM/Cloud Key/self-hosted console — gateways, switches, APs, firewall, cameras, and events.
- **[video-transcript](./video-transcript/SKILL.md)**: Turn a video link (YouTube, X, TikTok, Vimeo, Loom, and more) into metadata and a timestamped transcript: published captions first, speech-to-text when there are none, frames or Gemini for what is on screen.
